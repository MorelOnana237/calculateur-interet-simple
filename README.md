# calculateur-interet-simple
## Description
Ce programme calcule l'intérêt simple généré par un capital placé
pendant une durée donnée à un taux fixe.

## Formule
Intérêt = (Capital × Taux × Temps) / 100

- Capital (P) : somme initiale placée
- Taux (R) : taux d'intérêt annuel en %
- Temps (T) : durée en années

## Exemple
Capital = 100 000 FCFA, Taux = 5 %, Durée = 3 ans
Intérêt = (100 000 × 5 × 3) / 100 = 15 000 FCFA
Montant total = 115 000 FCFA

## Utilisation
1. Saisir le capital
2. Saisir le taux annuel
3. Saisir la durée
4. Le programme affiche l'intérêt et le montant total
